고백부터. 이 코드베이스에는 Jest가 세팅되어 있고 테스트 파일도 몇 개
있지만, 내가 작성한 테스트는 없었다. 기능은 늘 급했고, 테스트는 늘
"다음에"였다. 이 글은 그 부채를 갚기 시작하며 정리한 기준이다 —
**커버리지 0에서 첫 테스트는 어디에 써야 하는가.**

## 가장 불안한 곳이 아니라, 가장 잘 잘린 곳부터

직관은 "가장 위험한 코드부터 테스트하라"고 말한다. 결제 플로우,
예약 생성 같은 곳. 하지만 그런 코드는 대부분 네트워크와 전역 상태와
날짜와 브라우저 API가 뒤엉켜 있어서, 테스트를 쓰려면 먼저 모킹의
늪을 지나야 한다. 첫 테스트가 모킹 지옥이면 두 번째 테스트는 없다.

반대로 접근했다. **이미 순수하게 잘려 있는 코드부터.** 스토어를
slice로 리팩토링할 때 검증 규칙을 순수 함수로 분리해뒀었다.

```ts
// 오늘 이전이거나 현재 기준 2시간 이내인 체크인은 유효하지 않다
export const isCheckInValid = (checkIn: string): boolean =>
  !dayjs(checkIn).endOf('day').isBefore(dayjs().add(2, 'hour'));
```

입력은 문자열 하나, 출력은 불리언 하나. 네트워크도 상태도 없다.
그런데 이 한 줄에 도메인 규칙이 세 개나 눌려 있다 — 과거 날짜 거부,
"2시간 이내" 임박 거부, 그리고 `endOf('day')`가 만드는 경계.

## 순수해 보여도 시간은 숨은 입력이다

바로 함정이 나온다. 이 함수는 인자만 받는 것 같지만 `dayjs()` —
**현재 시각이라는 숨은 입력**이 있다. 그대로 테스트하면 밤 10시가
넘어 도는 CI에서만 실패하는 테스트가 된다(자정까지 2시간이 안 남아
"오늘"이 무효가 되는 순간이 실제로 있다).

시간을 고정하면 숨은 입력이 명시적 입력이 된다.

```ts
describe('isCheckInValid', () => {
  beforeEach(() => {
    jest.useFakeTimers().setSystemTime(new Date('2025-11-20T21:00:00'));
  });
  afterEach(() => jest.useRealTimers());

  it('어제 날짜는 무효다', () => {
    expect(isCheckInValid('2025-11-19')).toBe(false);
  });
  it('밤 9시, 오늘 체크인은 아직 유효하다 — 자정까지 3시간', () => {
    expect(isCheckInValid('2025-11-20')).toBe(true);
  });
  it('밤 11시라면 오늘 체크인은 무효다 — 2시간이 안 남았다', () => {
    jest.setSystemTime(new Date('2025-11-20T23:00:00'));
    expect(isCheckInValid('2025-11-20')).toBe(false);
  });
});
```

세 번째 케이스가 이 함수의 존재 이유다. 이런 경계는 수동 테스트로는
영원히 안 걸린다 — 밤 11시에 배포 확인을 하는 사람은 없으니까.

## 다음 후보는 판별 유니온의 분기

순수 함수 다음으로 값싼 대상은 **타입이 이미 경우의 수를 닫아둔
곳**이다. 리스트 렌더가 `itemType`으로 분기한다면, 각 가지에 아이템
하나씩 넣어 렌더 결과를 확인하는 테스트는 모킹 없이 써진다. 판별
유니온이 케이스를 열거해주므로 "빠뜨린 종류"가 없는지 타입과
테스트가 이중으로 지켜준다.

이렇게 줄을 세우면 우선순위가 저절로 나온다.

1. 순수 함수 (모킹 0개) — 도메인 규칙의 경계값
2. 판별 유니온 분기 렌더 (모킹 0~1개) — 종류별 스냅샷
3. 그다음에야 통합 플로우 — 위 두 층이 받쳐주면 모킹 범위가 줄어 있다

## 분리해두면 테스트는 따라온다

돌아보면 인과가 거꾸로였다. 테스트를 쓰려고 함수를 분리한 게 아니라,
**리팩토링하며 분리해둔 함수가 테스트를 공짜로 만들어줬다.** 테스트
작성이 어렵다는 건 대부분 테스트의 문제가 아니라 코드가 잘려 있지
않다는 신호다. 오늘 테스트를 못 쓰겠다면, 일단 순수한 조각 하나를
잘라내는 것부터가 시작이다.
